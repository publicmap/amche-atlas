One-time setup on your Google Sheet
  1. Open your sheet. Ideally the first row has columns named latitude, longitude, notes, timestamp, atlas, and layers — but you don't have to add them, the script creates any missing column on the first save.
  2. Go to Extensions → Apps Script, delete any placeholder code, and paste the script below.
  3. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone (not "Anyone with Google account" — that forces sign-in), then Deploy and approve the one-time authorization (you authorizing your own script — visitors never see it).
  4. Test it: open the /exec URL in an incognito tab — it should show {"status":"ok"}. If it asks you to sign in, re-check the access setting. After any script edit, redeploy via Manage deployments → Edit → New version.
  5. Copy the Web app URL (it ends in /exec) and paste it below.
