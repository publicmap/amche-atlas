# 10 minute quickstart

A first pass through [amche.in](https://amche.in) as a reader — no account, no setup.

## 1. Find yourself on the map

On first load the atlas asks for your location and centers the map there. If you'd rather type a place, use the search box in the header — it accepts addresses, place names and plot coordinates.

## 2. Turn layers on and off

The layer list in the header controls what's drawn on the map: cadastral plots, land-use zones, coastal limits, hazard maps and more, grouped by source. Toggle a layer to add or remove it from the view; layers stack in the order you check them, top layer first.

## 3. Inspect a feature

Click any plot, boundary or point to open its details — survey number, zone, source dataset and a link back to whoever published it. Nothing here is edited or interpreted by amche.in; it's a mirror of the original public record.

## 4. Switch the atlas

"Atlas" is amche.in's word for a themed collection of layers — Goa's cadastral atlas, a coastal-zone atlas, a disaster-management atlas, and so on. Switch between them from the atlas menu in the header without leaving the map.

## 5. Share what you're looking at

Every layer toggle, filter and camera move updates the page URL. Copy it and send it to someone — they land on exactly the same view. See [Using the URL API](?page=url-api) for everything a URL can carry.

## 6. Install it

amche.in is a Progressive Web App — install it from the menu for an offline-capable icon on your home screen or desktop.
