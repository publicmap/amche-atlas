Map Export Layout Template

This is a live template. js/export-layout.js loads the #export-layout-template elements and the #export-layout-style styles, places them over the export frame on the map, and draws the same elements onto every print export (PDF, PNG, JPEG, SVG) and the DXF raster. Edit the styles here to change how they look.

  • data-export-item - one element of the page: title, description, info, qr, scale, and a layer:<id> legend group per active map. Each is shown or hidden from the Export panel and dragged into place on the map; its position is kept as a percentage from the nearest page corner, so it lands in the same place at any page size.
  • title / description - edited in place on the map.
  • info - export time and the map's link.
  • data-export-qr - QR code of the map's link, sized by the link's length.
  • data-export-north-arrow - rotates with the map's bearing.
  • data-export-scale-label - ground distance of the 30mm scale bar on the page.
  • .legend-group - a map's name, attribution and detailed legend, built by js/export-legend.js (the example here is replaced); groups not yet moved are arranged in a column down the right of the page.
